This folder contains the raw housing dataset used in this project.

I downloaded the dataset from Kaggle:
https://www.kaggle.com/datasets/yasserh/housing-prices-dataset

To get the dataset, open the link above and click **Download**.

---

## 🏡 Why I Chose This Dataset

The goal of this project was to understand how housing data can be used to uncover the factors that influence property prices.

I selected this dataset because it provides realistic information such as income levels, room counts, population, and geographic coordinates. These are the same kinds of features that can be used to study real estate markets in fast-growing cities like Gurgaon, where prices are influenced by location, infrastructure, and demand.

Although the dataset is based on California housing data, it serves as an excellent proxy for learning how to analyze and prepare housing data in a practical, real-world context.

The same workflow developed in this project can later be applied to actual housing data from Gurgaon or any other city.
